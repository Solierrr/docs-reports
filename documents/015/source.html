Resumo da entrega

A disciplina de Experiência do Usuário pede um conjunto de entregáveis de pesquisa, desenho, prototipação e teste. Os 14 requisitos mínimos correspondem à nota 7,0, e os 3 extras ampliam a entrega.

O material de pesquisa e desenho do projeto fica no Figma e no Miro. O que faz parte dos repositórios (aplicativo Android, biblioteca de componentes e tokens de design) está versionado na branch main, e o requisito aponta para o arquivo que o comprova.

Como ler

Cada requisito aparece com o código (M para mínimo, E para extra), o enunciado, a descrição do que o projeto entregou e o link da evidência. Os links de GitHub abrem o arquivo na branch main. O link do Figma abre o arquivo de design do projeto, e o do Miro abre o board de diagramas.

A tabela de repositórios, no último capítulo, indica onde está cada arquivo versionado.
